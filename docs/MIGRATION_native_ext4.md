## 6. Root-cause evidence found for the original NTFS fault

- `v6/wfv` on the NTFS mount is a **pathological directory**: `stat` succeeds but directory
  iteration (`ls`, rsync `iterate_dir`) hangs indefinitely — an rsync worker sat in uninterruptible
  D-state on it for 6+ minutes and survived SIGINT/SIGTERM (required SIGKILL). This matches the
  hung smoke run (`tmp/p0_5_smoke_rerun_ntfs_hang_evidence.txt`): the orchestrator logged 4 lines
  at 03:15:15 and froze exactly where it touches `wfv/` (`setup_wfv_dirs()` / pre-slicing).
- `.git/config.lock` residue (Oct 20 14:46) on the NTFS repo — direct evidence of interrupted git
  writes on the mount.
- Separately: the earlier NTFS smoke run (02:46, `tmp/p0_5_smoke.txt`) already hit CUDA OOM
  (`cudaErrorMemoryAllocation`, failed to allocate 8000 bytes) — GPU contention predates the move.

## 8. Remaining issue: GPU VRAM contention (NOT a migration issue)

The `strata` inference server (PID 75087, the backend serving this agent session) holds
**15,530 MiB of 16,303 MiB VRAM at 99–100% utilization**. Only ~770 MiB free. Single-process GPU
jobs (parity test, individual window chains) fit and succeed; concurrent smoke workers (2 CUDA
contexts + RMM pools) exceed the remainder → `cudf.from_pandas` OOMs on trivial allocations
(8,000 / 172,800 bytes). Identical failure signature on NTFS and ext4 → contention, not filesystem.

Exact failing command (window 2 signal-gen, representative):

```
/home/archit-gore/venvs/rapids/bin/python /home/archit-gore/projects/indicator-based-algo-trading/v6/generate_vm_automation_logic_signals.py --mode smoke --data-csv /home/archit-gore/projects/indicator-based-algo-trading/v6/wfv/sliced_data/rows_384480_406080.csv --start-row 0 --end-row 21600 --output-dir /home/archit-gore/projects/indicator-based-algo-trading/v6/wfv/window_2_monthly_refine_2 --calibration /home/archit-gore/projects/indicator-based-algo-trading/v6/wfv/window_2_monthly_refine_2/calibration_results_vm.json
```

Per hard rules, the smoke run was executed **once** and not retried. Re-run the smoke pipeline when
the inference server is not holding VRAM (or with `--workers 1`) to expect exit 0.
